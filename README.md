# service-testing-skill

Claude Code skill that converts natural-language use-case specs (`UC-*.md`, `e2e-test-spec.md`) into ITIL-4/5-aligned Playwright E2E test suites — Page Object Models, test specs, and traceability/quality-gate reports. Proactively flags scenarios missing from the use case (negative paths, auth edge cases, resilience, concurrency, accessibility) and asks the user to confirm before adding them.
